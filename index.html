About

I'm 16, in 11th grade, based in India. I started with a low-end laptop (i5-4210U, 840M) and learned to care about every watt and every cycle because I had no choice. That stuck.

I built HPR because every activity tracker I found either needed an account, sent data to some server, or just didn't work on Linux. So I wrote my own. It runs on Windows and Linux, tracks everything locally, and has its own extension system.

Then I tried writing a programming language. First attempt was fully AI-generated. It compiled, sort of, but I couldn't debug it or extend it because I didn't understand what it was doing. So I deleted everything and rewrote it from scratch. Every line in tantrums is mine.

I like optimization, TDP tweaking, understanding OS internals, and building software that doesn't rely on 47 npm packages to print hello world.

HPR / Human Pattern Recorder

Compiled, offline, zero-account activity tracker

Watches your active window, logs usage history, and builds insights. All locally. No accounts, no telemetry by default, no server. Runs from the system tray on Windows and Linux. Data stored in plain SQLite files you can open with any viewer.

  • Cross-platform: Windows 10/11 + Linux (Hyprland, GNOME, KDE, Cinnamon, niri)
  • Lua 5.4 extension engine with hot-reload and EventHub
  • Custom theme system, full Slint UI replacement at runtime
  • Browser tab tracking via companion extension
  • App usage limits and daily goals with notifications
  • Advanced pattern analysis and day construction timeline
  • SQLite3 storage, one file per day, 30-100KB each
  • System tray with native D-Bus (Linux) and Win32 (Windows)

Statically typed, compiles to native executables through LLVM IR. Every component (lexer, parser, type checker, code generator) written by hand in C++23. The previous version was AI-generated. I scrapped it and rebuilt from zero because I didn't learn anything from it.

  • Recursive descent parser with precedence climbing
  • LLVM IR codegen, native types, no NaN-boxing
  • Function declarations, calls, arguments, and returns
  • Variable declaration, reassignment, and arithmetic expressions
  • Object emission and native linking (link.exe / ld.lld)
  • Type checker with scoped symbol table and bounds validation
